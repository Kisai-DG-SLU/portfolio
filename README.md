## Description

Projet final de la formation **AI Engineer** (Projet 15 — 60h). L objectif est de constituer un **portfolio professionnel** demontrant l ensemble des competences acquises tout au long du parcours, avec un focus sur le MLOps, la mise en production de solutions IA, et la gestion de projet data.

Le projet s appuie sur **SophIA**, une plateforme d orchestration d agents IA deployee sur cluster **OKD SNO bare-metal** (GPU NVIDIA Tesla A2), comme projet technique phare.

---

## Objectifs pedagogiques

| Competence | Description |
|-----------|-------------|
| Collecte des besoins metiers | Analyse du contexte organisationnel et recueil des exigences |
| Audit de solution data | Evaluation de l adequation technique aux besoins |
| Identification de solution technique | Choix d architecture, technologies, outils |
| Appui strategique | Aide a la decision, analyse risques/opportunites |
| Controle et pilotage | Suivi delais, couts, livrables, performance |

## Stack technique

| Domaine | Technologies |
|---------|-------------|
| Orchestration | OKD (OpenShift), Kubernetes |
| Conteneurisation | Docker, Podman, CRI-O |
| IA/ML | Agents LLM autoheberges, RAG, Qdrant |
| Infrastructure | Bare-metal SNO, GPU NVIDIA Tesla A2, SCOS |
| CI/CD | Forgejo, BuildConfig, GitOps |
| Monitoring | Prometheus, Grafana, node-exporter |
